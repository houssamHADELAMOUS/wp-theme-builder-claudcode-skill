== Description ==

{{NAME}} is a block theme built with theme.json, editable templates and patterns. Site content types and custom blocks are provided by the companion plugin "{{NAME}} Core", which should stay active when changing themes.

== Installation ==

1. In your admin panel, go to Appearance > Themes and click Add New.
2. Click Upload Theme and choose the zip file.
3. Click Activate.
4. Install and activate the "{{NAME}} Core" plugin if your site uses custom content types.

== Frequently Asked Questions ==

= Does this theme support any plugins? =

{{NAME}} works with any well-coded plugin. It has been tested with the block editor and the companion plugin.

= How do I change colours and fonts? =

Go to Appearance > Editor > Styles. Choose a style variation or adjust the palette and typography within the presets provided.
